# 脫敏水印

[简体中文](README.md) · **繁體中文** · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

**幫照片加水印，並清掉會暴露你的拍攝資訊。**

原生 Android 應用程式，適配手機和平板。在本機批次處理 HEIF、JPEG、PNG 等常見格式。浮水印可以隨機避開畫面中心，匯出時預設移除相機參數、拍攝時間和地理位置。

**不連網，不上傳任何資訊。** 全部處理都在你的裝置上完成：應用程式沒有網路權限，照片、浮水印、設定和檔名都不會離開這台手機或平板。

英文名 **Safe Photo Mark**。系統需求為 **Android 8.0 或更新版本**。介面提供簡體中文、繁體中文、英語、日語和韓語，跟隨系統語言。目前為公測，已知問題還比較多，正式版敬請期待。另外還有適用於 Apple Silicon 的原生 Mac 應用程式。

## 安全與隱私

- **不連網**：應用程式沒有網路權限（不會申請 `INTERNET`），也不會發起網路請求。
- **不上傳任何資訊**：照片、浮水印、設定和檔名都只留在這台裝置上。
- **只在本機執行**：全部處理都在你的手機或平板上完成，不經過任何伺服器。
- **沙盒限制**：只讀寫你選取的照片、浮水印檔案和輸出資料夾，不申請整個儲存空間或相簿權限。
- **不覆蓋原圖**：結果寫到你指定的資料夾，預設加上 `_safephotomark` 後綴。

## 功能

- **批次加浮水印**：透明 PNG 或 SVG，可調大小和不透明度，一次處理多張照片。
- **移除中繼資料（預設開啟）**：清除拍攝參數、時間、地理位置等；關閉後會盡量保留拍攝資訊，但仍會去掉原圖縮圖，並把方向改成正向。
- **位置**：一行切換「手動 / 隨機 / 固定」。手動可在預覽裡拖曳；隨機會避開畫面中心 30% 區域，且浮水印始終不出畫；固定使用九宮格方位。
- **格式**：支援 JPEG、PNG、HEIF/HEIC、TIFF、GIF、BMP，以及裝置能讀取的 WebP。輸出可選 JPEG、PNG、HEIF、TIFF，或與原圖相同。
- **隨機重新命名**：可把輸出改成 12 位隨機檔名，避免檔名裡的拍攝日期。
- **匯入照片**：可用系統相簿選擇器多選，也可從檔案或資料夾匯入。單次最多 2000 張。
- **處理完成提示音**：批次處理結束後可播放提示音，能在設定裡關閉。
- **記住設定**：輸出資料夾和浮水印路徑會記住，下次打開還能用。
- **自適應介面**：手機上預覽優先、設定可捲動，開始按鈕固定在底部左側；平板和寬螢幕使用與桌面版相近的三欄佈局（列表 | 預覽 | 設定）。

## 下載與安裝

目前版本 **3.0**，僅為公測。需要 **Android 8.0 或更新版本**。已知問題還比較多，正式版敬請期待。

1. 從 [Releases](https://github.com/izja16/SafePhotoMark/releases/latest) 下載 `SafePhotoMark-3.0.apk`。
2. 把 APK 拷到手機或平板上並開啟。若系統提示「禁止安裝未知來源應用程式」，請依提示允許，這不是應用程式損壞。
3. 安裝完成後，在應用程式列表裡開啟「脫敏水印」。

本安裝包尚未經過應用程式商店審核，需要你手動允許安裝。

## 支援的格式

**輸入：** JPEG、PNG、HEIF/HEIC（`.heic`、`.heif`、`.hif`）、TIFF、GIF、BMP，以及裝置能解碼的 WebP。HEIF 解碼通常需要 Android 9 或更新版本。

**輸出：** JPEG、PNG、HEIF（`.heic`）、TIFF。選擇「與原圖相同」時，JPEG / PNG / HEIF / TIFF 保持對應格式；GIF、BMP 及無法識別的格式匯出為 JPEG；WebP 匯出為 PNG（本應用程式不寫出 WebP，這樣可保留透明通道）。

GIF 和多幀 HEICS 都只匯出第一幀。

部分裝置無法編碼 HEIF。若你選擇了 HEIF，或「與原圖相同」且原圖是 HEIF，而裝置無法編碼，該檔案會明確失敗，而不會悄悄改存為 JPEG。

## 中繼資料會移除什麼

「移除中繼資料」預設開啟。開啟時，輸出是全新寫入的檔案，不會從原圖拷貝中繼資料，包括拍攝參數、時間、GPS、IPTC/XMP、MakerNote、原圖縮圖，以及相機 ICC（輸出統一為 sRGB）。

關閉後會盡量保留拍攝資訊（在 Android 上，JPEG 和部分 HEIF 可透過系統 ExifInterface 寫回；PNG 和 TIFF 的保留能力有限），但方向標籤仍會改成正向，原圖縮圖仍會去掉。

16 位元和 Display P3 等廣色域原圖會轉換為 8 位元 sRGB 後再處理。一次最多匯入 2000 張；取消只會停止尚未完成的工作，已經寫出的檔案不會回滾。

## 隨機位置

浮水印必須完整落在畫布內。隨機模式下，浮水印中心會避開照片正中 30% × 30% 的區域。若浮水印太大，則在畫布內任意合法位置隨機。每張照片的位置會記住，可在預覽裡拖曳，匯出使用同一位置。固定位置使用九宮格，並留出約 4% 短邊的邊距。

## 權限

應用程式不會申請網路權限，也不會申請整個相簿或儲存空間的讀取權限。照片透過系統照片選擇器或檔案選擇器匯入；浮水印和輸出資料夾透過系統檔案選擇器授權，並可記住上次選擇的位置。

## 從原始碼編譯

需要 **Android Studio**（Android Gradle Plugin 8.7、JDK 17），以及 Android SDK Platform 35 與 Build-Tools 35。用 Android Studio 開啟本目錄（GitHub 倉庫中為 `android/`），同步 Gradle 後執行 `app` 模組。

```
./gradlew :app:assembleRelease
./gradlew test
```

請在 `local.properties` 中設定 `sdk.dir`。發布版 APK 會出現在 `app/build/outputs/apk/release/`。本機建置可以使用一次性上傳金鑰簽名，方便直接安裝；該金鑰不會提交到版本庫。

SVG 浮水印由 [AndroidSVG](https://bigbadaboom.github.io/androidsvg/)（Apache 2.0 授權）光柵化。它涵蓋常見 SVG，但不是完整的 SVG 2。第三方授權說明見 `THIRD_PARTY.md`。
