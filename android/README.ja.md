# 脱敏水印 / Safe Photo Mark

[简体中文](README.md) · [繁體中文](README.zh-Hant.md) · [English](README.en.md) · **日本語** · [한국어](README.ko.md)

**写真に透かしを付け、あなたを特定できてしまう撮影情報を取り除きます。**

スマートフォンとタブレット向けの **ネイティブ Android アプリ**です。HEIF、JPEG、PNG などの一般的な形式を端末上で一括処理します。透かしは画面中央を避けてランダムに配置でき、書き出し時はカメラ設定、撮影日時、位置情報をデフォルトで削除します。

**ネットワークには接続せず、何もアップロードしません。** すべての処理はこの端末で完結します。アプリに INTERNET 権限はなく、写真、透かし、設定、ファイル名はこのスマートフォンまたはタブレットから出ません。

中国語名は **脱敏水印**。必要な環境は **Android 8.0 以降**です。現時点では公開ベータであり、既知の不具合がかなりあります。正式版をお待ちください。界面はシステム言語に従い、簡体字中国語、繁体字中国語、英語、日本語、韓国語に対応します。Apple Silicon 向けのネイティブ Mac アプリもあります。

## 安全とプライバシー

- **非接続**：INTERNET 権限がなく、ネットワークリクエストも行いません。
- **非アップロード**：写真、透かし、設定、ファイル名はこの端末だけに残ります。
- **ローカルのみ**：すべての処理はスマートフォンまたはタブレット上で行われ、サーバーを経由しません。
- **サンドボックス**：選択した写真、透かしファイル、出力フォルダだけを読み書きし、ストレージやフォトライブラリ全体へのアクセスは求めません。
- **元画像は上書きしません**：結果は指定したフォルダへ書き出し、デフォルトで `_safephotomark` を付けます。

## 機能

- **一括透かし**：透明 PNG または SVG。サイズと不透明度を調整できます。
- **メタデータの削除（デフォルトでオン）**：撮影設定、日時、位置情報などを削除します。オフのときは Android が許す範囲で撮影情報を残しますが、埋め込みサムネイルは除き、向きは正立にします。
- **配置**：手動 / ランダム / 固定を一行で切り替え。手動はプレビューでドラッグ、ランダムは中央 30% を避けて画内に収め、固定は九分割です。
- **形式**：JPEG、PNG、HEIF/HEIC、TIFF、GIF、BMP、および端末が読める WebP。出力は JPEG、PNG、HEIF、TIFF、またはソースと同じ。
- **ランダムな名前の変更**：12 文字のランダムなファイル名にできます。
- **読み込み**：システムの写真ピッカー（複数選択）、またはファイルとフォルダ。一度に最大 2000 枚。
- **完了音**（設定でオフにできます）。
- **設定の記憶**（透かしと出力フォルダを含む）。
- **適応レイアウト**：スマートフォンではプレビュー優先、開始ボタンは下部バーの左寄せ。タブレットと広い画面ではリスト | プレビュー | 設定の 3 ペインです。

## インストール

現在のバージョンは **3.0** の公開ベータです。**Android 8.0 以降**が必要です。既知の不具合がかなりありますので、正式版をお待ちください。

1. [Releases](https://github.com/izja16/SafePhotoMark/releases/latest) から `SafePhotoMark-3.0.apk` を入手します。
2. APK を端末にコピーして開きます。システムが「不明な提供元」からのインストールをブロックした場合は、指示に従って許可してください。アプリが壊れているわけではありません。
3. インストール後、アプリ一覧から「脱敏水印」を開きます。

アプリストア経由ではないため、手動での許可が必要です。

## 対応形式

**入力：** JPEG、PNG、HEIF/HEIC（`.heic`、`.heif`、`.hif`）、TIFF、GIF、BMP、および端末が復号できる WebP。HEIF の読み込みには通常 Android 9 以降が必要です。

**出力：** JPEG、PNG、HEIF（`.heic`）、TIFF。「ソースと同じ」のとき、JPEG / PNG / HEIF / TIFF はその形式のまま、GIF・BMP・不明な形式は JPEG、WebP は PNG になります（このアプリは WebP を書き出さないため、透明を残せます）。GIF と複数フレームの HEICS は先頭フレームのみです。

一部の端末は HEIF を書き出せません。HEIF を選んだ場合、または「ソースと同じ」で元が HEIF の場合、書き出せなければ明確に失敗し、JPEG へ黙って切り替えません。

## メタデータ

「メタデータを削除」がオンのときは、新しいファイルとして書き出し、EXIF、撮影日時、GPS、IPTC/XMP、MakerNote、サムネイル、カメラ ICC（出力は sRGB）をコピーしません。オフのときは可能な範囲で残しますが（JPEG と一部の HEIF）、向きは正立、サムネイルは除きます。16 ビットや Display P3 などの広色域は 8 ビット sRGB に変換します。一度に最大 2000 枚。キャンセルは未完了の作業だけを止め、既に書いたファイルは戻しません。

## ランダム配置

透かしは必ず画内に収まります。ランダムでは中心が中央 30% × 30% を避け、避けられないときは画内の任意の位置になります。各写真の位置は記憶され、書き出しで再利用できます。固定は短辺の約 4% の余白付き九分割です。

## 権限

ネットワーク権限も、ストレージや写真全体への一括権限も申請しません。写真はシステムピッカーまたはドキュメントピッカーから、透かしと出力フォルダはストレージアクセスフレームワークで許可し、前回の場所を覚えられます。

## ソースからビルド

**Android Studio**（Android Gradle Plugin 8.7、JDK 17）、SDK Platform 35、Build-Tools 35 が必要です。このディレクトリ（GitHub リポジトリでは `android/`）を開き、`app` を実行します。

```
./gradlew :app:assembleRelease
./gradlew test
```

`local.properties` に `sdk.dir` を設定します。リリース APK は `app/build/outputs/apk/release/` に出力されます。SVG のラスタライズには [AndroidSVG](https://bigbadaboom.github.io/androidsvg/)（Apache 2.0）を使います。詳細は `THIRD_PARTY.md`。
